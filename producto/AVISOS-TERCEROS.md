# Avisos de terceros

TurboFrame usa componentes de código abierto y recursos libres. Todos permiten el uso comercial. Sus licencias completas se instalan con `npm install`, junto a cada paquete en `node_modules/`.

| Recurso | Origen | Licencia | Obligación |
|---|---|---|---|
| `assets/audio/kenney/` (efectos) | Kenney (kenney.nl): RPG Audio, Interface Sounds, Impact Sounds, Digital Audio | CC0 | Ninguna |
| `assets/samples/vsco2-ce/` (piano, arpa, cuerdas; convertidos a OGG) | Versilian Studios, VSCO 2 Community Edition | CC0 | Ninguna |
| `assets/countries.json` (nombres de países) | i18n-iso-countries | MIT | Ninguna |
| `world-atlas` (fronteras) | Natural Earth vía world-atlas | Dominio público / ISC | Ninguna |
| `es-atlas` (comunidades y provincias) | Instituto Geográfico Nacional vía es-atlas | CC BY 4.0 / ISC | Citar «© IGN» cuando se muestre |
| Tipografías `@fontsource/*` | Google Fonts | OFL 1.1 (Permanent Marker y Special Elite: Apache 2.0) | Ninguna para vídeo |
| Iconos `lucide-static`, `@tabler/icons` | Lucide, Tabler | ISC / MIT | Ninguna |
| Banderas `flag-icons` | flag-icons | MIT | Ninguna |
| `three`, `animejs`, `d3`, `roughjs`, `topojson-client` | — | MIT / ISC | Ninguna |
| `hyperframes` | — | Apache 2.0 | Telemetría desactivada con `HYPERFRAMES_NO_TELEMETRY=1` |
